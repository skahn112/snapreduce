# SnapReduce – Free Online Image Compression & Optimization Platform

SnapReduce is a browser-based image processing platform built with Next.js App Router, TypeScript, and Tailwind CSS. Image processing is performed locally in the user's browser, with no backend image-upload dependency.

## Key Features

- **Client-Side Image Processing:** Image reading, resizing, compression, and format conversion are performed locally in the browser.
- **Exact-Size Compression:** Target-size compression supports thresholds such as 50KB, 100KB, 200KB, and 500KB.
- **Image Compression:** Compress JPG, PNG, WebP, and other supported image formats.
- **Image Resizing:** Resize images while maintaining dimensions and aspect ratios.
- **Image Conversion:** Convert between supported image formats.
- **Image Cropping:** Crop images directly in the browser.
- **Image Calculators:** Aspect ratio, dimensions, and DPI calculation tools.
- **SEO Landing Pages:** Dedicated pages for common image compression and resizing queries.
- **Blog System:** Technical guides, tutorials, comparisons, and image optimization resources.
- **Structured Data:** JSON-LD support for WebSite, WebApplication, BreadcrumbList, Article, and FAQ content.
- **Technical SEO:** Dynamic sitemap, robots.txt, canonical URLs, metadata, and internal linking.
- **Monetization Ready:** Dedicated ad-slot components for future advertising integration.
- **Legal Pages:** About, Contact, Privacy Policy, Terms, Disclaimer, and FAQ pages.

## Tech Stack
